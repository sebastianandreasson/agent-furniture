# Domain docs

QueryCAD is a single-context repository.

Before architecture, diagnosis, or test-design work, read:

- `CONTEXT.md` for the canonical furniture-design vocabulary;
- relevant decisions under `docs/adr/`;
- `AGENTS.md` for build, coordinate, export, and fabrication constraints.

Use the exact terms defined in `CONTEXT.md` in code, tests, issues, and documentation. If a durable
new concept is introduced, add it to the glossary. If a durable architectural choice would otherwise
be re-litigated, record it as an ADR.
